# 贡献指南

欢迎改进 FDE 专业知识和工程实践，先确认相关卡片不存在，优先修正原卡而非复制一份。

1. 提 Issue / Draft PR，写清问题、受影响的人、来源证据、预期使用场景。
2. 增加或修正知识卡时，必须同时检查 `registry/SOURCES.md` 的来源与权利状况。
3. 任何具体业务指标、第三方引语与“亲历经验”均须明确是谁的陈述、是否独立复核及公开授权；无证据可保留假设但不可伪装为事实。
4. 不提交客户工单、企业账号、工作聊天、截图中姓名、未授权图片、Token 等个人/商业敏感内容。
5. PR 检查：引用有效、相对路径正确、Mermaid 可解析、变更可逆、无空目录、没有未授权执行依赖；测试未运行须清楚写“未运行”。
6. 同一问题的资料优先维护一张主卡；属于技能原件的修复请提交到 `xingtu-skills` 等拥有者仓库。
7. 所有自动化接入都必须先以独立 PR 讨论权限和撤回策略，禁止直接对公开仓启动 Feishu/GitHub 主动执行。

内容许可证尚未确定，在选定开源协议前请仅提交本人原创并明确授权可公开的内容；第三方文献保留链接与必要短引用。
