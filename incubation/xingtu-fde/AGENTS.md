# Agents 工作约束

所有 Agent / 贡献者在本仓操作前必须遵循：
1. 先查 `registry/REPOS.md` 和 `registry/SOURCES.md`；优先链接原文件，避免全文搬运。
2. 将每条结论明确标注为：`source_claim`（来源自述）、`independently_verified`（有独立复核证据）、`hypothesis`（假设）、`synthetic`（合成示例）。不得自动晋级。
3. 区分源类型 `official` / `first_party` / `third_party` / `synthetic`。官方项目 README 的声明也只是其自身产品状态，不能直接推导生产可靠性。
4. 绝不公开敏感资料：真实雇主、客户、同事、私人聊天、账号、私有路径、令牌、商业秘密；脱敏不足时仅在私有工作流保存引用。
5. 对外记录协作过程需区分“忠实整理/摘要”和“逐字原始记录”，未经授权不得公示原始对话。
6. Agent 可研究、写 Draft PR、执行本地静态验证；禁止未经单独授权的部署、发布、PR 合并、自动机器人接入和跨客户数据同步。
7. 修改文档必须列出原始 URL、已核实范围、未核实点、权限影响和回退方式，随 PR 记录。
8. 默认中文文档；可提供简短英文摘要。将格式变化和能力建设分开提交；不为凑结构创建空目录。
