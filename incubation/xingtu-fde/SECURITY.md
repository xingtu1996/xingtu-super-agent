# 安全与私密信息披露规范

本项目为**公共知识仓**，不是客户交付资料存储，也不是执行器沙箱。

**禁止提交**：企业和个人可识别信息、客户订单/内部财务/合同、账号密码及 API 密钥、会话原始记录、内网 URL/设备路径、未授权截图和受版权保护的文章全文。若需要讨论，只写必要的脱敏、可证实摘要。

**问题处理**：发现泄露时停止扩散，在 GitHub 私密渠道联系维护者处理；不要先发公开 Issue 粘贴凭证。需要撤回时同时审查 Git 历史、PR 评论和被同步的下游内容；仓库删除或单纯改文件不等于泄露回收成功。

**执行边界**：所有插件、Source、机器人、Agent、CI 与外部服务默认未接入。未来试点按最小权限、独立测试身份、显式授权、幂等副作用记录、人工审批和回滚逐步开放。不得基于一份会话或 Prompt 提升权限。
