# 架构决策记录（2026-11-02）

## ADR-001：XSA 独立建仓，而不是留在 xingtu-harness 实验目录

- 状态：已采纳（2026-11-02，用户决策）
- 背景：Event Bridge v0.1 以实验 PR 形式存放在 xingtu-harness 的 `experiments/` 下，产品定位、治理与受众与 harness 的「工程资产聚合」职责不同。
- 决策：创建独立公开仓 `xingtu1996/xingtu-super-agent` 作为产品主线；实验材料逐字节迁移并保留来源 PR 与提交出处；xingtu-harness 保持原状（工程资产及安装聚合），旧 PR 与历史不删除、不改写。
- 影响：两仓通过文档引用与协议演进协作；跨仓变更各自走 PR。迁移清单见 `../../MIGRATION_MANIFEST.md`。

## ADR-002：能力接力，而非全能 Agent

- 状态：已采纳（2026-11-02）
- 背景：不同 Agent 的能力面存在结构性差异（例：规划/审核环境没有建仓接口；Personal Agent 有 GitHub 操作能力但不应自审自批）。试图让单个 Agent 拥有所有工具，既不现实，也绕不过各平台的授权与接口限制。
- 决策：XSA 只建设最小控制平面（Task / Event / Receipt 契约、能力声明与路由、授权门禁、回执、Watchdog），执行复用已有 Agent；任务按能力、成本、成功率、隐私与风险分配给专业执行者；执行证据回流后由其他 Agent 独立验收。
- 边界：XSA 不突破平台授权、安全或接口限制；没有接口的平台只做人工交接并如实标注 `manual`；自动接力在 Event Bridge 验证完成前一律标 `design`，不得宣传为已实现。
